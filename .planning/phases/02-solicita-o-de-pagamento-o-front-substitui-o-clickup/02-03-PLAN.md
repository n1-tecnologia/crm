Criar `apps/api/migracoes/003-integracao-e-importacao.sql` seguindo a convenção de 001/002 (idempotente por `if not exists`, comentário de cabeçalho em pt-BR explicando por que cada tabela existe, nenhum `drop`). Cinco tabelas no schema `plataforma`:

`plataforma.integration_outbox` — `id uuid primary key default gen_random_uuid()` (é também o `eventId`/idempotency key do receptor), `workspace_id text not null`, `aggregate_type text not null`, `aggregate_id text not null`, `event_type text not null`, `event_version int not null default 1`, `payload jsonb not null`, `status text not null default 'pending'` com `check (status in ('pending','delivering','delivered','failed'))`, `attempts int not null default 0`, `available_at timestamptz not null default now()`, `locked_at timestamptz`, `locked_by text`, `last_error_code text`, `last_error_summary text`, `created_at timestamptz not null default now()`, `delivered_at timestamptz`. Índice parcial `(available_at, id) where status = 'pending'` para o worker reivindicar; índice `(aggregate_type, aggregate_id)`. Constraint única `(aggregate_type, aggregate_id, event_type)` para `event_type = 'solicitacao.criada.v1'` — implementada como índice único parcial, porque uma Tarefa nasce uma vez só e o invariante V02-07A ("um e só um evento por commit") precisa ser do banco, não do código.

`plataforma.http_idempotency` — `service_id text not null`, `route_template text not null`, `idempotency_key text not null`, `request_hash text not null`, `status text not null` com `check (status in ('in_progress','completed'))`, `response_status int`, `response_body jsonb`, `created_at timestamptz not null default now()`, `completed_at timestamptz`, primary key `(service_id, route_template, idempotency_key)`. Índice em `created_at` para a limpeza depois de 90 dias.

`plataforma.service_credentials` — `id text primary key` (o prefixo público do token), `workspace_id text not null`, `nome text not null`, `secret_hash text not null` (sha-256 do segredo; **nunca** o segredo), `scopes text[] not null`, `member_id text not null` (o Membro `Agente do pipeline` que a credencial representa — D-15), `state text not null default 'ativa'` com `check (state in ('ativa','rotacionando','revogada'))`, `created_at`, `last_used_at`, `revoked_at`. Índice parcial `(workspace_id) where state <> 'revogada'`.

`plataforma.upload_sessions` — `id uuid primary key default gen_random_uuid()`, `workspace_id text not null`, `form_id text not null`, `created_at timestamptz not null default now()`, `expires_at timestamptz not null`, `consumed_at timestamptz`, `object_count int not null default 0`. Tabela filha `plataforma.upload_objects` — `id uuid primary key default gen_random_uuid()`, `session_id uuid not null references plataforma.upload_sessions(id) on delete cascade`, `object_key text not null unique`, `display_name text not null`, `media_type text not null`, `size_bytes bigint`, `sha256 text`, `state text not null default 'reservado'` com `check (state in ('reservado','enviado','consumido','expirado'))`, `created_at timestamptz not null default now()`. O `unique (object_key)` é o que impede reusar um objeto de outra submissão (T-02-06).

`plataforma.importacao_ledger` — `origem text not null`, `legacy_task_id text not null`, `run_id uuid not null`, `task_id text`, `resultado text not null` com `check (resultado in ('importada','rejeitada','avisada'))`, `motivo text`, `source_hash text not null`, `created_at timestamptz not null default now()`, primary key `(origem, legacy_task_id)`. Índice em `(run_id, resultado)` para o relatório de reconciliação. O `motivo` é texto curto de categoria (por exemplo `taskid_ausente`, `aprovado_ambiguo`), nunca o conteúdo da linha de origem.

Nenhuma coluna destas tabelas guarda CPF/CNPJ, chave Pix, código de barras, conteúdo de anexo ou segredo — registrar isso como comentário SQL em cada tabela que poderia tentar (`integration_outbox.payload`, `importacao_ledger.motivo`, `http_idempotency.response_body`).
