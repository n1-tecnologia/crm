No `automation/`, extrair a montagem do `codigo_lancamento_integracao` para uma função pura `codigoDeIntegracao({ origem, taskId }): string` que devolve `tria:payment-request:<origem>:<taskId>` — determinística, sem timestamp, sem aleatoriedade. Para a coorte `plataforma`, **recusar** qualquer caminho que não consiga montar o código: ausência de `taskId` é erro, nunca fallback com `Date.now()`. Para a coorte `clickup`, preservar o comportamento atual, inclusive o fallback existente, porque é o caminho de rollback e não pode mudar de forma — registrar a assimetria em comentário.

No caminho do Omie, impor a ordem: `ConsultarContaPagar(codigo)` **antes** de `IncluirContaPagar`; se encontrar, reutilizar e não incluir. Criar `codigo-de-integracao.test.ts` (node:test, `criarOmieFalso`) cobrindo:
(a) `codigoDeIntegracao` é determinístico: duas chamadas com a mesma entrada devolvem a mesma string, e origens diferentes devolvem strings diferentes para o mesmo `taskId`;
(b) coorte `plataforma` sem `taskId` → erro, nunca código com timestamp;
(c) consulta antes de incluir: com o código já presente no Omie falso, `incluir` não é chamado;
(d) `incluirComConexaoCaida` seguido de retry → a consulta encontra o código e `chamadas.length === 1`;
(e) o caminho `clickup` continua produzindo o código como hoje — regressão explícita;
(f) `grep` estático: o caminho da plataforma não contém `Date.now()`.
